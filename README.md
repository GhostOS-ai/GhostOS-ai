### 🌟 Flagship Project: [GhostOS](https://github.com/GhostOS-ai/GhostOS)

An ultra-lightweight desktop AI companion and copilot that runs smoothly on standard laptops and base Apple Silicon Macs (4GB–8GB RAM) without out-of-memory (OOM) crashes.

```bash
pip install ghostos-ai
ghost pet
```

#### ✨ Highlights
- **⚡️ Native WebViews:** Featherweight GUI idling at `<35MB RAM` (no Electron bloat).
- **🧠 Dynamic VRAM Juggler:** Hot-swaps LLM, Vision, and Whisper in `<150ms`, keeping peak VRAM `≤3.5GB`.
- **📂 Zero-DB RAG:** Instant file search & chat powered by pure **SQLite FTS5**.
- **✍️ Ghostwriter:** Inline text completion & tone rewrite across all apps via clipboard.
- **🛡 Terminal Sandbox Lens:** Proactive command safety interceptor (`rm -rf`, `DROP TABLE`).
- **🔒 100% Offline & Private:** Zero telemetry, air-gapped ready.

### 🛠️ Quick CLI Cheatsheet

| Command | Action |
| :--- | :--- |
| `ghost pet` | Launch floating Casper pet & Spotlight HUD |
| `ghost "your question"` | Instant offline question answering |
| `ghost eat ./notes/` | Feed local documents to Zero-DB RAG |
| `ghost write --mode polite` | Rewrite clipboard text in polite tone |
| `ghost standup` | Generate daily standup report & git commits |
| `ghost status` | Inspect live RAM/VRAM memory juggler state |
